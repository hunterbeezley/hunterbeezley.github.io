aTOBIN

2024 TouchDesigner, Audio Reactive

About This Project

aTOBIN is an audio-reactive visualization that explores the intersection of algorithmic motion and dynamic color transformation. The piece responds in real-time to audio input, translating sonic frequencies into visual motion and chromatic shifts. Each musical moment generates unique geometric patterns and color palettes, creating an immersive dialogue between sound and sight.

Technical Approach

Built in TouchDesigner, aTOBIN utilizes audio analysis operators to extract frequency data across multiple bands. This data drives particle systems, geometric deformations, and shader-based color shifting. The system maintains algorithmic complexity while remaining responsive to subtle audio nuances, creating smooth transitions between visual states.

Real-time GPU processing enables high-resolution output suitable for live performance or installation contexts.
